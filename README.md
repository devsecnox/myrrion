## Projects

### [Security Log Analyzer](https://github.com/devsecnox/security-log-analyzer)
A Python-based simulation and data analytics script. 
* Generates synthetic security log data representing common attack types (DDoS, SQLi, Malware, Phishing).
* Uses Pandas for data cleaning and statistical missing value imputation (handling null data fields via mean computation).
* Utilizes Seaborn and Matplotlib to export visual distribution charts regarding risk scores and mitigation frequency.
